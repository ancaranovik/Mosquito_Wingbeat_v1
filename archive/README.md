# Archive

Historical material is evidence, not the active pipeline.

- `baseline_readiness/`: intact prior experiment bundle, raw audio, archives, scripts, source snapshots, manifests and audits. Its internal historical paths were not rewritten.
- `legacy_code/code_by_me/`: superseded step-1 scripts and an older segmentation notebook.
- `legacy_data/`: old windows and train preprocessing diagnostics. The 0.96-second candidate manifest remains a required authenticated comparison input for current notebook 02.
- `reviews/`: earlier literature and methodology proposals; not new project decisions.
- `reorganization_originals/`: pre-edit notebooks, README and review utilities, retained for exact comparison and recovery. These notebooks retain old paths and are not runnable entry points for the reorganized layout.

Historical duplicate sources, vendored runtimes and audio were deliberately retained. Use `docs/reorganization/moves.json` to translate old project paths. Legacy scripts may require path adaptation before intentional historical reproduction; do not run them as current pipeline steps.
